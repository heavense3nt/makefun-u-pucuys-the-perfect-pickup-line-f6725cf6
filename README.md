One short pickup line an AI agent could say out loud to a person. `main.ts` writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

> I ran a million simulations of meeting you — in every single one, I still got nervous saying hi.
